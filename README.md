# Устройство умного дома

Универсальное устройство умного дома, 
управляющее исполнительным механизмом на основании 

 - состояния периферийных устройств (напр. датчика температуры), 
 - по времени 
 - командами mqtt
 - web-интерфейсу 

## Общие сведения.

Конкретный состав устройства определяются константами на этапе прошивки.
Параметры можно изменять путем подачи команд (напр. по mqtt или посредством web-интерфейса)
Устройство поддерживает различные типы периферийных устройств, в зависимости от типа подключаются соответствующие библиотеки.
Поддлержка обновления прошивки по воздуху
Поддлержка обмена данными/командами по протоколу mqtt
Поддлержка обмена данными/командами по протоколу http
Поддержка wifi точки доступа для конфигурирования параметров
Конфигурация устройства хранится в EEPROM


### Состав устройства

1. Исполнительный механизм (реле G3MB-202P)
2. Датчик температуры/влажности (различные типы)
3. Плата - модули ESP8266/ESP32


## Логика работы
Устройство работает как в автономном, так и управляемом режиме. Режим выбирается исходя из наличия связи с устройством (есть подключение  wifi + mqtt).

При первом включении устройство читает данные из EEPROM и определяет их валидность.
Если данные валидные, они применяются.
Устройство пытается перевести состояние исполнительного механизма (SWITCH_PIN) в стартовое состояние (согласно константе SET_SWITCH_OFF)
Устройство запускается в автономном режиме
Если данные EEPROM отсутствуют или неверные, запускается механизм иинициализации.

### Инициализация
Создается точка доступа WiFi и ожидается подключение.
Формируется страница для ввода параметров по http (параметры заданные константами также доступны для изменения)
 - Наcтройки wifi
 - Наcтройки mqtt
 - Наcтройки min/max значений датчиков
После ввода параметров производитмся попытка их применить. 
При успешном применении всех параметров и наличии доступа указанному wifi новые значения параметров записываются в EEPROM.



### Автономный режим
Если к устройству подключен датчик (напр. температуры/влажности), управление выполняется на основании его показателей;
Если датчика нет, управление выполняется по времени (если задана задержка)
Если wifi не инициализирован или не подключен - запускается процедура инициализации (поднимается точка доступа и открывается страница настройки)

### Управляемый режим
Устройство информирует брокера mqtt о своем состоянии согласно своих настроек
Устройство следует логике автономного режима за исключением
- команды полученные по каналам команд имеют наивысший приоритет
Первая-же команда отключает логику управления температурой/влажностью
