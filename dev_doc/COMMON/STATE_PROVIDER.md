## 1. Назначение

`StateProvider` — общая шина статусной информации, обеспечивающая обмен данными между слоями без прямых связей. Предоставляет единый механизм доступа к статусам транспорта и событиям кнопки для всех компонентов системы.

Слой является факультативным: его отключение не влияет на работу базовой логики `DeviceController`, но ограничивает функциональность индикации и диагностики.

## 2. Архитектурное место

```
┌─────────────────────────────────────────────────────────────────────┐
│                              ОРКЕСТРАТОР                            │
│                                                                     │
│  • Инициализирует StateProvider                                     │
│  • Читает статусы для принятия решений                              │
│  • Реагирует на события кнопки                                      │
└─────────────────────────────────────────────────────────────────────┘
          │                    │                      │
          │          ┌─────────┴──────────┐           │
          │          ▼                    ▼           │
          │    ┌───────────────────────────────────┐  │
          │    │          STATE PROVIDER           │  │
          │    │   (глобальная структура)          │  │
          │    │                                   │  │
          │    │  • link_ok       // от Transport  │  │
          │    │  • gateway_ok    // от Transport  │  │
          │    │  • setup_mode    // от Transport  │  │
          │    │  • button_stage  // от Button     │  │
          │    └───────────────────────────────────┘  │
          │                    ▲                      │
          │                    │                      │
          ▼                    │                      ▼
┌───────────────────┐          │        ┌─────────────────────────────┐
│  Transport        │──────────┘        │  ButtonManager              │
│  (пишет статусы)  │                   │  (пишет события)            │
└───────────────────┘                   └─────────────────────────────┘
```

**Потоки данных:**
- `Transport → StateProvider`: запись статусов подключения (`link_ok`, `gateway_ok`, `setup_mode`)
- `ButtonManager → StateProvider`: запись стадии нажатия (`button_stage`)
- `StateProvider → Оркестратор`: чтение для принятия решений
- `StateProvider → LED`: чтение для определения режима индикации

**Важно:** `DeviceController` **НЕ ИМЕЕТ ДОСТУПА** к StateProvider.

## 3. Ответственность

| Ответственность | Описание |
|-----------------|----------|
| **Хранение статусов транспорта** | `link_ok`, `gateway_ok`, `setup_mode` |
| **Хранение событий кнопки** | `button_stage` |
| **Предоставление доступа** | Публичные поля для чтения/записи |

**Права доступа:**

| Поле | Владелец (пишет) | Читатели |
|------|------------------|----------|
| `link_ok` | Transport | Оркестратор, LED |
| `gateway_ok` | Transport | Оркестратор, LED |
| `setup_mode` | Transport | Оркестратор, LED |
| `button_stage` | ButtonManager | Оркестратор |

**Важно:**
- Слой **НЕ ДОЛЖЕН** писать в чужие поля
- `DeviceController` **НЕ ИМЕЕТ ДОСТУПА** к StateProvider
- Оркестратор **НЕ ПИШЕТ** в StateProvider, только читает

## 4. Структуры данных

`StateProvider` содержит статусную информацию, определённую в `common_types.h`:

### 4.1. StateProvider

```cpp
class StateProvider {
public:
    // ===== СТАТУСЫ ТРАНСПОРТА =====
    bool link_ok;        ///< Соединение с точкой доступа (WiFi/Zigbee)
    bool gateway_ok;     ///< Соединение с брокером/шлюзом (MQTT/HTTP)
    bool setup_mode;     ///< Режим настройки (AP режим)
    
    // ===== СОБЫТИЯ КНОПКИ =====
    ButtonStage button_stage;  ///< Стадия нажатия (BUTTON_IDLE, BUTTON_SHORT, BUTTON_MID, BUTTON_LONG, BUTTON_HOLD)
};
```

### 4.2. ButtonStage (из common_types.h)

```cpp
enum ButtonStage : uint8_t {
    BUTTON_IDLE = 0,   ///< Кнопка отпущена
    BUTTON_SHORT = 1,  ///< Нажата 0-1с
    BUTTON_MID = 2,    ///< Нажата 1-2с
    BUTTON_LONG = 3,   ///< Нажата 2-3с
    BUTTON_HOLD = 4    ///< Нажата >3с
};
```

## 5. Интерфейс

Публичный интерфейс слоя:

```cpp
class StateProvider {
public:
    /**
     * @brief Инициализация провайдера состояния
     * @return true при успешной инициализации
     */
    bool init();
    
    // ===== СТАТУСЫ ТРАНСПОРТА =====
    bool link_ok;        ///< Соединение с точкой доступа
    bool gateway_ok;     ///< Соединение с брокером/шлюзом
    bool setup_mode;     ///< Режим настройки (AP)
    
    // ===== СОБЫТИЯ КНОПКИ =====
    ButtonStage button_stage;  ///< Стадия нажатия
};
```

**Важно:** Интерфейс минималистичен — только инициализация и публичные поля. Методы доступа (геттеры/сеттеры) отсутствуют сознательно для снижения оверхеда.

## 6. Жизненный цикл

### 6.1. Инициализация

```cpp
// main.cpp
StateProvider g_stateProvider;

void setup() {
    // 1. Инициализация логгера
    // 2. Инициализация ConfigManager
    // 3. Инициализация StateProvider
    g_stateProvider.init();
    
    // 4. Инициализация остальных слоёв
}
```

**Начальные значения:**
- `link_ok = false`
- `gateway_ok = false`
- `setup_mode = false`
- `button_stage = BUTTON_IDLE`

### 6.2. Запись (обновление)

**ButtonManager** обновляет `button_stage` в своём методе `update()`:

```cpp
void ButtonManager::update() {
    // Чтение GPIO, антидребезг, подсчёт времени
    
    if (isPressed) {
        ...
        if (duration > 3000) {
            g_stateProvider.button_stage = BUTTON_HOLD;
        } else if (duration > 2000) {
            ...
        }
    }
}
```
