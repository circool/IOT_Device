# CREDENTIALS.md

## Заводские настройки (credentials.h)

---

## 1. Назначение

Файл `credentials.h` содержит **заводские настройки** устройства, которые используются при первом запуске или после сброса конфигурации.

**Назначение:**
- Хранение WiFi SSID/пароля для первоначального подключения
- Хранение MQTT-настроек (брокер, порт, учётные данные)
- Обеспечение "бесшовного" первого запуска без необходимости ручной настройки

**Важно:** файл **не должен** попадать в репозиторий (добавлен в `.gitignore`).

---

## 2. Правила работы с credentials.h

| # | Правило | Описание |
|---|---------|----------|
| 1 | **Опциональность** | Файл не обязателен. Если отсутствует — используются жёстко заданные дефолты |
| 2 | **Изоляция** | Все макросы имеют значения по умолчанию, если не определены в `credentials.h` |
| 3 | **Шаблонизация** | В репозитории лежит `credentials.template.h` с пустыми значениями для копирования |
| 4 | **Защита** | Файл добавлен в `.gitignore` и не должен коммититься |
| 5 | **Приоритет** | Значения из `credentials.h` имеют приоритет над жёсткими дефолтами, но могут быть переопределены через Web/MQTT |

---

## 3. Структура

Файл организован по логическим группам. **Принцип:** каждая группа содержит параметры, относящиеся к одному компоненту системы. Это упрощает чтение и модификацию.

**Группы:**
1. **WiFi** — `SSID_NAME`, `WIFI_PASSWORD`
2. **MQTT** — `MQTT_ADDRESS`, `MQTT_PORT`, `MQTT_USER`, `MQTT_PASSWORD`

---

## 4. Параметры

### 4.1. WiFi

| Параметр | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| `SSID_NAME` | Строка | ✅ Да | Имя WiFi сети |
| `WIFI_PASSWORD` | Строка | ❌ Нет | Пароль (может быть пустым для открытых сетей) |

### 4.2. MQTT

| Параметр | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| `MQTT_ADDRESS` | Строка | ✅ Да | IP-адрес или домен брокера |
| `MQTT_PORT` | `uint16_t` | ✅ Да | Порт (по умолчанию 1883) |
| `MQTT_USER` | Строка | ❌ Нет | Имя пользователя (если требуется аутентификация) |
| `MQTT_PASSWORD` | Строка | ❌ Нет | Пароль (если требуется аутентификация) |

---

## 5. Интеграция с ConfigManager

**Принцип:** загрузка значений из `credentials.h` происходит **только** при установке значений по умолчанию (`setDefaults()`).

| Механизм | Описание |
|----------|----------|
| **Проверка наличия** | Используется `__has_include` на этапе компиляции |
| **Флаг `HAS_CREDENTIALS`** | Устанавливается автоматически, если файл найден |
| **Загрузка значений** | Выполняется в `ConfigManager::setDefaults()` |
| **Приоритет** | Значения из `credentials.h` → жёсткие дефолты → пользовательские настройки из EEPROM |

---

## 6. Шаблонизация

| Файл | Назначение |
|------|------------|
| `credentials.h` | Реальный файл с секретами (в `.gitignore`) |
| `credentials.template.h` | Шаблон с пустыми значениями (в репозитории) |

**Правило:** пользователь копирует `credentials.template.h` → `credentials.h` и заполняет своими значениями.

---

## 7. Альтернативные подходы

| Подход | Применимость |
|--------|--------------|
| **credentials.h** | Основной подход для разработки и производства |
| **build_flags в platformio.ini** | Для CI/CD, где нет возможности создать файл |
| **Environment variables** | Для безопасного хранения секретов вне кода |

**Рекомендация:** использовать `credentials.h` для разработки, `build_flags` для CI/CD.
