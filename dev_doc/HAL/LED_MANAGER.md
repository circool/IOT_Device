## 1. Назначение

Слой `LedManager` обеспечивает визуальную индикацию состояния устройства. Менеджер не содержит логики принятия решений — он получает готовый режим от оркестратора через метод `setMode()` и применяет его, управляя GPIO.

Слой инкапсулирует управление пином и реализацию паттернов мигания.

## 3. API

### 3.1. init()

```cpp
void init();
```

**Назначение:** инициализация пина светодиода.

**Параметры:** отсутствуют (используются константы `STATUS_LED_PIN`, `LED_INVERTED`).

**Возвращаемое значение:** отсутствует.

---

### 3.2. setMode()

```cpp
void setMode(LedMode mode);
```

**Назначение:** установка режима индикации.

**Параметры:**
- `mode` — режим из `LedMode`

**Возвращаемое значение:** отсутствует.

**Поведение:**
- Сохраняет режим для применения в `update()`
- Логирует смену режима на уровне `DEBUG`

---

### 3.3. update()

```cpp
void update();
```

**Назначение:** обновление физического состояния светодиода.

**Параметры:** отсутствуют.

**Возвращаемое значение:** отсутствует.

**Поведение:**
- Вызывается в `loop()`
- Применяет текущий режим
- Использует `millis()` для неблокирующего мигания
- Обновляет состояние пина только при изменении

## 4. Режимы индикации

| Режим | Сигнал | Период | Длительность импульса | Назначение |
|-------|--------|--------|----------------------|------------|
| `LED_OFF` | Постоянно выключен | — | — | Сохранение настроек / перезагрузка |
| `LED_ON` | Постоянно включён | — | — | Нормальная работа |
| `LED_MORZE_E` | 1 вспышка | Интервал настраивается* | 100 мс | Потеря WiFi |
| `LED_MORZE_I` | 2 вспышки | Интервал настраивается* | 100 мс (каждая) | Потеря MQTT или удержание 1-2с |
| `LED_MORZE_S` | 3 вспышки | Интервал настраивается* | 100 мс (каждая) | Режим настройки или удержание >2с |
| `LED_SLOW_BLINK` | Медленное мигание | 2000 мс | 1000 мс | Аварийное отключение |

\* Интервал между сериями настраивается через константу `LED_SERIES_INTERVAL_MS`.

### 4.1. Детали паттернов

Все паттерны строятся на основе серии длительностью 1000 мс:

| Режим | Структура серии |
|-------|-----------------|
| `LED_MORZE_E` | 100 мс ON, 900 мс OFF |
| `LED_MORZE_I` | 100 мс ON, 100 мс OFF, 100 мс ON, 700 мс OFF |
| `LED_MORZE_S` | 100 мс ON, 100 мс OFF, 100 мс ON, 100 мс OFF, 100 мс ON, 500 мс OFF |
| `LED_SLOW_BLINK` | 1000 мс ON, 1000 мс OFF (период 2000 мс) |

### 4.2. Управление частотой серий

Частота повторения серий настраивается через константу `LED_SERIES_INTERVAL_MS`:

| `LED_SERIES_INTERVAL_MS` | Эффект |
|--------------------------|--------|
| 1000 | Серия каждую секунду (без паузы) |
| 1500 | Серия 1с, пауза 0.5с |
| 2000 | Серия 1с, пауза 1с |
| 3000 | Серия 1с, пауза 2с |

**Важно:** длительность серии всегда 1000 мс. При увеличении интервала добавляется пауза между сериями.

## 5. Интеграция с оркестратором

```cpp
void loop() {
    // 1. Физическое обновление LED
    g_ledManager.update();
    
    // 2. Определение режима
    if (stage == BUTTON_IDLE) {
        // Кнопка не нажата — логика по StateProvider
        if (g_stateProvider.link_ok && g_stateProvider.gateway_ok) {
            g_ledManager.setMode(LED_ON);
        } else if (!g_stateProvider.link_ok) {
            g_ledManager.setMode(LED_MORZE_E);
        } else if (!g_stateProvider.gateway_ok) {
            g_ledManager.setMode(LED_MORZE_I);
        } else {
            g_ledManager.setMode(LED_OFF);
        }
    } else {
        // Кнопка нажата — логика по стадии
        switch (stage) {
            case BUTTON_MID:
                g_ledManager.setMode(LED_MORZE_I);
                break;
            case BUTTON_LONG:
            case BUTTON_WARN:
                g_ledManager.setMode(LED_MORZE_S);
                break;
            case BUTTON_HOLD:
                g_ledManager.setMode(LED_OFF);
                break;
            default:
                break;
        }
    }
}
```

**Приоритеты (от высшего к низшему):**

| Приоритет | Режим | Условие |
|-----------|-------|---------|
| 1 | `LED_OFF` | Сброс настроек (`BUTTON_HOLD`) |
| 2 | `LED_MORZE_S` | Удержание кнопки >2с (`BUTTON_LONG`/`BUTTON_WARN`) |
| 3 | `LED_MORZE_I` | Удержание кнопки 1-2с (`BUTTON_MID`) |
| 4 | `LED_MORZE_E` | Нет `link_ok` (потеря WiFi) |
| 5 | `LED_MORZE_I` | Нет `gateway_ok` (потеря MQTT) |
| 6 (низший) | `LED_ON` | Всё работает |

## 6. Настройка

| Флаг | По умолчанию | Описание |
|------|--------------|----------|
| `FEATURE_LED_ENABLED` | — | Пользовательский флаг включения слоя |
| `STATUS_LED_PIN` | `0` | Номер GPIO светодиода |
| `LED_INVERTED` | `0` (ESP32) / `1` (ESP8266) | Инверсия логики: `0` = HIGH включён, `1` = LOW включён |
| `LED_SERIES_INTERVAL_MS` | `1000` | Интервал между сериями (мс) |

Внутренний флаг `USE_LED` определяется в `settings.h` на основе `FEATURE_LED_ENABLED`. При отключении слоя все методы становятся пустыми заглушками.

**Пример включения:**
```ini
build_flags =
    -D FEATURE_LED_ENABLED=1
    -D STATUS_LED_PIN=2
    -D LED_INVERTED=1
    -D LED_SERIES_INTERVAL_MS=2000
```
