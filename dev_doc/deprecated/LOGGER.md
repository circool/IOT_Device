## 1. Назначение

Единая система логирования для всего проекта. Обеспечивает:

- **Фильтрацию** — логирование только нужных уровней и категорий
- **Цветной вывод** — визуальное различие уровней в консоли
- **Гибкую настройку** — через макросы сборки или в рантайме
- **Минимальный размер** — код логирования исключается, если `FEATURE_LOGGER_ENABLED=0`

## 2. Уровни логирования

| Уровень | Значение | Описание |
|---------|----------|----------|
| `XLOG_LEVEL_NONE` | 0 | Логи полностью отключены |
| `XLOG_LEVEL_ERROR` | 1 | Только критические ошибки |
| `XLOG_LEVEL_WARN` | 2 | Предупреждения + ERROR |
| `XLOG_LEVEL_INFO` | 3 | Основные события + WARN + ERROR |
| `XLOG_LEVEL_DEBUG` | 4 | Всё (максимальная детализация) |

## 3. Категории логирования

Категории позволяют включать/отключать логи для конкретных компонентов.

| Категория | Бит | Описание |
|-----------|-----|----------|
| `CAT_CONFIG` | 1 << 0 | Конфигурация и EEPROM |
| `CAT_SENSOR` | 1 << 1 | Датчик температуры/влажности |
| `CAT_FAN` | 1 << 2 | Вентилятор |
| `CAT_SWITCH` | 1 << 3 | Выключатель |
| `CAT_ACTUATOR` | 1 << 4 | Базовый актуатор |
| `CAT_MQTT` | 1 << 5 | MQTT-клиент |
| `CAT_WIFI` | 1 << 6 | WiFi-менеджер |
| `CAT_WEB` | 1 << 7 | Веб-интерфейс |
| `CAT_OTA` | 1 << 8 | OTA-обновления |
| `CAT_LED` | 1 << 9 | LED-индикация |
| `CAT_WDT` | 1 << 10 | Сторожевой таймер |
| `CAT_AP` | 1 << 11 | Точка доступа |
| `CAT_MAIN` | 1 << 12 | Оркестратор (main.cpp) |
| `CAT_PROVISIONING` | 1 << 13 | Провизионинг |
| `CAT_BLE` | 1 << 14 | BLE-сервер |
| `CAT_BUTTON` | 1 << 15 | Кнопка управления |
| `CAT_RESTART` | 1 << 16 | Менеджер перезагрузок |
| `CAT_SYSTEM` | 1 << 17 | Системное состояние |
| `CAT_DEVICE` | 1 << 18 | DeviceController |
| `CAT_STATE` | 1 << 18 | DeviceState |
| `CAT_ALL` | 0xFFFFFFFF | Все категории |

## 4. API

### 4.1. Инициализация

**Метод:** `Logger::getInstance().init()`

**Параметры:**

| Параметр | Тип | Описание | Значение по умолчанию |
|----------|-----|----------|----------------------|
| `level` | `LogLevel` | Максимальный уровень для вывода | `XLOG_LEVEL_INFO` |
| `categories` | `uint32_t` | Битовая маска разрешённых категорий | `CAT_ALL` |
| `useColor` | `bool` | Использовать ANSI-цвета | `true` |

**Правила:**
- Вызывается один раз в `setup()` **первым** (до всех остальных слоёв)
- Настройки могут быть переопределены через `build_flags` (см. раздел 5)

---

### 4.2. Макросы для логирования

**Архитектурный контракт:**

| Макрос | Уровень | Назначение |
|--------|---------|------------|
| `XLOG_ERROR(cat, fmt, ...)` | ERROR | Критические ошибки, требующие внимания |
| `XLOG_WARN(cat, fmt, ...)` | WARN | Предупреждения, нефатальные проблемы |
| `XLOG_INFO(cat, fmt, ...)` | INFO | Основные события (запуск, подключение, переключение режимов) |
| `XLOG_DEBUG(cat, fmt, ...)` | DEBUG | Отладочная информация (показания датчиков, детали) |

**Правила использования:**
- Категория (`cat`) — один из макросов из раздела 3
- Формат (`fmt`) — printf-стиль с поддержкой `%d`, `%s`, `%f` и т.д.
- Сообщение должно быть информативным и содержать контекст

---

### 4.3. Управление фильтрацией

**Методы для рантайм-настройки:**

| Метод | Параметры | Назначение |
|-------|-----------|------------|
| `set_level(LogLevel level)` | Уровень | Изменить максимальный уровень вывода |
| `set_categories(uint32_t categories)` | Битовая маска | Изменить разрешённые категории |
| `is_enabled(bool enabled)` | Включить/выключить | Включить или отключить цветной вывод |

## 5. Настройка через build_flags

| Флаг | Тип | Описание | Значение по умолчанию |
|------|-----|----------|----------------------|
| `XLOG_LEVEL` | `int` (0-4) | Максимальный уровень | 4 (DEBUG) |
| `XLOG_CATEGORIES` | `uint32_t` | Битовая маска категорий | `0xFFFFFFFF` (все) |
| `XLOG_USE_COLOR` | `int` (0/1) | Цветной вывод | 1 |
| `MONITOR_SPEED` | `int` | Скорость Serial (бод) | 115200 |

**Правила:**
- Если `XLOG_CATEGORIES` не задан — включены все категории
- Если `FEATURE_LOGGER_ENABLED=0` — все макросы становятся пустыми (экономия Flash)

---

## 6. Цветной вывод

Цвета используются для визуального различения уровней:

| Уровень | Цвет | ANSI-код |
|---------|------|----------|
| ERROR | Красный | `ANSI_BRIGHT_RED` |
| WARN | Маджента |`ANSI_BRIGHT_MAGENTA`|
| INFO | Обычный |  |
| DEBUG | Синий | `ANSI_BLUE` |

**Правила:**
- Цвета можно отключить через `XLOG_USE_COLOR=0` или метод `is_enabled(false)`
- Цвета выводятся только если Serial поддерживает ANSI (терминал, PlatformIO)
