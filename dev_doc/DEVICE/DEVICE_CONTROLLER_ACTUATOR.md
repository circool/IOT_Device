## 1. Назначение

`Actuator` — внутренний компонент `DeviceController`, обеспечивающий управление физическими выходами (реле, ШИМ).

**Статус:** ✅ **Реализован** (v0.13)

## 3. Компоненты

### 3.1. ActuatorBase — базовый класс

**Назначение:** дискретное управление нагрузкой (ON/OFF) + таймеры.

**Ответственность:**
- Управление пином (HIGH/LOW)
- Таймер отложенного включения (`delaySeconds`)
- Таймер аварийного отключения (`maxOnTime` → `emergency`)

**Колбэки (указатели на функции):**

| Колбэк | Сигнатура | Назначение |
|--------|-----------|------------|
| `onSetPhysicalCallback` | `void(*)(void*, bool)` | Вызов при изменении состояния пина |
| `onForceStopCallback` | `void(*)(void*)` | Вызов при аварийной остановке |
| `onManualCommandCallback` | `void(*)(void*)` | Вызов при ручной команде |

**Состояние:**

| Поле | Тип | Назначение |
|------|-----|------------|
| `_state` | bool | Текущее состояние (true=вкл) |
| `_startTime` | unsigned long | Время последнего включения |
| `_delayActive` | bool | Активен ли таймер отложенного включения |
| `_delayTimer` | unsigned long | Время срабатывания таймера |
| `_emergencyStop` | bool | Аварийное отключение |

**Методы:**

| Метод | Назначение |
|-------|------------|
| `init()` | Инициализация пина |
| `set(on, manual)` | Установить состояние |
| `getState()` | Получить состояние |
| `update(delaySeconds, maxOnTime)` | Периодическая обработка |
| `forceStop()` | Аварийное выключение |

---

### 3.2. FanActuator — вентилятор с ШИМ

**Назначение:** управление вентилятором с регулировкой скорости (TYPE 1).

**Ответственность:**
- ШИМ-управление (частота 500 Гц, разрешение 8 бит)
- Стартовый импульс (100% на 200 мс)
- Хранение флага `adaptiveMode` (логика в DeviceController)

**Дополнительные параметры:**

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `PWM_FREQUENCY` | 500 Гц | Частота ШИМ |
| `PWM_FREQUENCY` | 5 Гц | Частота ШИМ для коллектотрного двигателя |
| `PWM_RESOLUTION` | 8 бит | Разрешение ШИМ |
| `PWM_STARTING` | 200 мс | Длина стартового импульса |
| `MIN_SPEED_PERCENT` | 10% | Минимальная скорость |

**Особенности:**
- При включении с `speed < 100%` и `speed >= MIN_SPEED_PERCENT` — стартовый импульс
- При `speed = 0` — вентилятор выключается
- При `speed >= 100` — ШИМ отключается (полная мощность)

**Платформы:** ESP8266, ESP32, ESP32-S2, ESP32-S3, ESP32-C3, ESP32-C6, ESP32-H2

---

### 3.3. SwitchActuator — выключатель

**Назначение:** управление выключателем без ШИМ (TYPE 3).

**Ответственность:**
- Только ON/OFF (через `ActuatorBase`)
- Прокси-класс — все методы делегируются `ActuatorBase`

```
ActuatorBase
    ▲
    │

    │   • ШИМ-управление
    │   • Стартовый импульс
    │   • getSpeed() / setSpeed()
    │
    └── SwitchActuator (DEVICE_TYPE == 3)
        • Только ON/OFF
        • Прокси-класс
```

## 6. Логика работы

### 6.1. Стартовый импульс (FanActuator)

```
Включение со скоростью 1-99%:
1. Подаётся 100% мощность на 200 мс
2. Затем снижается до заданной скорости

Включение со скоростью 100%:
1. Сразу полная мощность (без импульса)

Включение со скоростью 0%:
1. Вентилятор не включается
```

### 6.2. Таймер отложенного включения (ActuatorBase)

```
1. При вызове update() проверяется условие:
   - delaySeconds > 0
   - актуатор выключен
   - таймер не активен
2. Таймер запускается на delaySeconds секунд
3. По истечении — актуатор включается в ручном режиме
```

### 6.3. Аварийное отключение (ActuatorBase)

```
1. При вызове update() проверяется время работы
2. Если elapsed >= maxOnTime → forceStop()
3. forceStop() → выключение + _emergencyStop = true
4. Сброс — только при ручном включении
```
