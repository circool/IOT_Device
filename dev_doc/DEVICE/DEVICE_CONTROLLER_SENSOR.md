## 1. Назначение

`Sensor` — внутренний компонент `DeviceController`, обеспечивающий чтение показаний температуры и влажности с физического датчика.

**Статус:** ✅ **Реализован** (v0.13)

## 3. Ответственность

| Область | Ответственность |
|---------|-----------------|
| **Чтение данных** | Опрос физического датчика с соблюдением минимального интервала |
| **Валидация** | Проверка показаний на NaN и допустимые диапазоны |
| **Обработка ошибок** | Подсчёт ошибок чтения, инвалидация датчика при превышении порога |
| **Предоставление данных** | Геттеры для температуры, влажности, статуса валидности |

**Sensor НЕ ЗНАЕТ:**
- О бизнес-логике DeviceController
- О транспорте и публикации
- О ConfigManager

## 4. Структура данных

```cpp
typedef struct {
    // ===== ПУБЛИЧНЫЕ ПОЛЯ (для чтения) =====
    bool valid;          // TRUE = данные валидны
    float temperature;   // Температура в °C
    float humidity;      // Влажность в %
    char error[32];      // Текст последней ошибки

    // ===== ВНУТРЕННИЕ ПОЛЯ (не трогать) =====
    unsigned long lastReadTime;  // Время последнего чтения
    uint8_t readErrors;          // Счётчик ошибок подряд
    bool initialized;            // Флаг инициализации
    uint8_t type;                // 1 = AHT10, 2 = DHT
    int pin;                     // GPIO (для DHT) или -1 (для I2C)
} Sensor;
```

## 5. Публичный интерфейс

```cpp
/**
 * @brief Инициализация датчика
 * @param sensor Указатель на Sensor
 * @param type Тип датчика (1 = AHT10, 2 = DHT)
 * @param pin GPIO пин (для DHT) или -1 (для I2C)
 * @return true при успехе
 */
bool sensor_init(Sensor* sensor, uint8_t type, int pin);

/**
 * @brief Обновление показаний датчика
 * @param sensor Указатель на Sensor
 * @return true если данные обновились
 */
bool sensor_update(Sensor* sensor);

/**
 * @brief Проверка валидности данных
 */
static inline bool sensor_isOk(const Sensor* sensor) {
    return sensor->valid;
}

/**
 * @brief Получить температуру
 */
static inline float sensor_getTemperature(const Sensor* sensor) {
    return sensor->temperature;
}

/**
 * @brief Получить влажность
 */
static inline float sensor_getHumidity(const Sensor* sensor) {
    return sensor->humidity;
}

/**
 * @brief Получить текст ошибки
 */
static inline const char* sensor_getError(const Sensor* sensor) {
    return sensor->error;
}
```

## 6. Логика работы

### 6.1. Инициализация (`sensor_init()`)

1. Сохраняет тип и пин датчика
2. Инициализирует I2C (для AHT10) или GPIO (для DHT)
3. Выполняет первое чтение для проверки
4. Устанавливает флаг `initialized`

### 6.2. Обновление (`sensor_update()`)

1. Проверяет минимальный интервал опроса
2. Читает данные с физического датчика
3. Валидирует показания:
   - Проверка на NaN
   - Влажность в диапазоне 0-100%
4. При успехе:
   - Обновляет `temperature`, `humidity`
   - Устанавливает `valid = true`
   - Сбрасывает `readErrors`
5. При ошибке:
   - Увеличивает `readErrors`
   - При `readErrors >= SENSOR_ERROR_THRESHOLD` → `valid = false`

### 6.3. Обработка ошибок

| Условие | Действие |
|---------|----------|
| `isnan(temp)` или `isnan(hum)` | Ошибка чтения |
| `hum < 0` или `hum > 100` | Ошибка валидации |
| 3 ошибки подряд | `valid = false` |
| Успешное чтение после ошибок | `valid = true` (восстановление) |

## 7. Поддерживаемые датчики

| Тип | Датчик | Интерфейс | Минимальный интервал |
|-----|--------|-----------|---------------------|
| `SENSOR_TYPE = 1` | AHT10 | I2C | 100 мс |
| `SENSOR_TYPE = 2` | DHT11 / DHT22 | 1-Wire | 1000 мс (DHT11) / 2000 мс (DHT22) |

## 8. Константы

| Константа | Значение | Описание | Файл |
|-----------|----------|----------|------|
| `SENSOR_TYPE` | 1 или 2 | Тип датчика | `settings.h` |
| `I2C_SDA_PIN` | 21 (ESP32) / 4 (ESP8266) | SDA для I2C | `settings.h` |
| `I2C_SCL_PIN` | 22 (ESP32) / 5 (ESP8266) | SCL для I2C | `settings.h` |
| `SENSOR_PIN` | 16 (ESP32) / 4 (ESP8266) | GPIO для DHT | `settings.h` |
| `DHT_TYPE` | DHT11 или DHT22 | Тип DHT | `settings.h` |
| `SENSOR_ERROR_THRESHOLD` | 3 | Ошибок до invalid | `device_controller_sensor.cpp` |
