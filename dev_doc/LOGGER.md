## 1. Назначение

Слой `logger` обеспечивает единую систему логирования для всего проекта.

**Возможности:**
- Фильтрация по уровням и категориям
- Цветной вывод в консоль
- Гибкая настройка через макросы сборки и в рантайме
- Минимальный размер кода (исключается при `FEATURE_LOGGER_ENABLED=0`)

Слой реализован как набор функций (без класса), что минимизирует накладные расходы.

---

## 2. Уровни логирования

| Уровень | Значение | Описание |
|---------|----------|----------|
| `XLOG_LEVEL_NONE` | 0 | Логи полностью отключены |
| `XLOG_LEVEL_ERROR` | 1 | Только критические ошибки |
| `XLOG_LEVEL_WARN` | 2 | Предупреждения + ERROR |
| `XLOG_LEVEL_INFO` | 3 | Основные события + WARN + ERROR |
| `XLOG_LEVEL_DEBUG` | 4 | Всё (максимальная детализация) |

## 3. Категории логирования

Категории позволяют включать/отключать логи для конкретных компонентов.

| Категория | Бит | Описание |
|-----------|-----|----------|
| `CAT_CONFIG` | 1 << 0 | Конфигурация и EEPROM |
| `CAT_SENSOR` | 1 << 1 | Датчик температуры/влажности |
| `CAT_FAN` | 1 << 2 | Вентилятор |
| `CAT_SWITCH` | 1 << 3 | Выключатель |
| `CAT_ACTUATOR` | 1 << 4 | Базовый актуатор |
| `CAT_MQTT` | 1 << 5 | MQTT-клиент |
| `CAT_WIFI` | 1 << 6 | WiFi-менеджер |
| `CAT_WEB` | 1 << 7 | Веб-интерфейс |
| `CAT_OTA` | 1 << 8 | OTA-обновления |
| `CAT_LED` | 1 << 9 | LED-индикация |
| `CAT_WDT` | 1 << 10 | Сторожевой таймер |
| `CAT_AP` | 1 << 11 | Точка доступа |
| `CAT_MAIN` | 1 << 12 | Оркестратор (main.cpp) |
| `CAT_PROVISIONING` | 1 << 13 | Провизионинг |
| `CAT_BLE` | 1 << 14 | BLE-сервер |
| `CAT_BUTTON` | 1 << 15 | Кнопка управления |
| `CAT_RESTART` | 1 << 16 | Менеджер перезагрузок |
| `CAT_SYSTEM` | 1 << 17 | Системное состояние |
| `CAT_DEVICE` | 1 << 18 | DeviceController |
| `CAT_TRANSPORT` | 1 << 19 | Транспортный слой |
| `CAT_STATE` | 1 << 20 | StateProvider |
| `CAT_ALL` | 0xFFFFFFFF | Все категории |

## 4. API

### 4.1. Инициализация

```cpp
void log_init(LogLevel level = (LogLevel)XLOG_LEVEL,
              uint32_t categories = XLOG_CATEGORIES,
              bool useColor = XLOG_USE_COLOR);
```

**Назначение:** инициализация системы логирования.

**Параметры:**

| Параметр | Тип | Описание | Значение по умолчанию |
|----------|-----|----------|----------------------|
| `level` | `LogLevel` | Максимальный уровень для вывода | `XLOG_LEVEL` |
| `categories` | `uint32_t` | Битовая маска разрешённых категорий | `XLOG_CATEGORIES` |
| `useColor` | `bool` | Использовать ANSI-цвета | `XLOG_USE_COLOR` |

**Правила:**
- Вызывается один раз в `setup()` **первым**
- Настройки могут быть переопределены через `build_flags` (см. раздел 5)

**Пример:**
```cpp
void setup() {
    log_init(XLOG_LEVEL_INFO, CAT_ALL, true);
    // ...
}
```

### 4.2. Макросы для логирования

| Макрос | Уровень | Назначение |
|--------|---------|------------|
| `XLOG_ERROR(cat, fmt, ...)` | ERROR | Критические ошибки, требующие внимания |
| `XLOG_WARN(cat, fmt, ...)` | WARN | Предупреждения, нефатальные проблемы |
| `XLOG_INFO(cat, fmt, ...)` | INFO | Основные события (запуск, подключение) |
| `XLOG_DEBUG(cat, fmt, ...)` | DEBUG | Отладочная информация (детали) |

**Пример:**
```cpp
XLOG_ERROR(CAT_CONFIG, "Config read failed: %d", err);
XLOG_WARN(CAT_WIFI, "WiFi connection timeout");
XLOG_INFO(CAT_MAIN, "Device started, version %s", VERSION);
XLOG_DEBUG(CAT_SENSOR, "Temperature: %.1f°C", temp);
```

**Правила использования:**
- Категория (`cat`) — один из макросов из раздела 3
- Формат (`fmt`) — printf-стиль (`%d`, `%s`, `%f`, `%lu` и т.д.)
- Сообщение должно быть информативным и содержать контекст
- Отладочные сообщения всегда логируются с `XLOG_DEBUG`

**Проверка активности:**
```cpp
if (XLOG_ENABLED(XLOG_LEVEL_DEBUG, CAT_SENSOR)) {
    // Дорогое вычисление только для отладки
    XLOG_DEBUG(CAT_SENSOR, "Complex value: %f", calculate());
}
```

### 4.3. Управление фильтрацией

**Методы для рантайм-настройки:**

| Функция | Параметры | Назначение |
|---------|-----------|------------|
| `log_set_level(LogLevel level)` | Уровень | Изменить максимальный уровень вывода |
| `log_set_categories(uint32_t categories)` | Битовая маска | Изменить разрешённые категории |
| `log_set_color(bool enabled)` | Включить/выключить | Включить или отключить цветной вывод |
| `log_is_enabled(LogLevel level, LogCategory category)` | Уровень, категория | Проверить, будет ли выведено сообщение |

**Пример:**
```cpp
// Включить только ERROR и WARN
log_set_level(XLOG_LEVEL_WARN);

// Отключить отладочные категории
log_set_categories(CAT_ALL & ~CAT_SENSOR & ~CAT_WIFI);

// Отключить цвета для терминала без поддержки ANSI
log_set_color(false);
```

## 5. Настройка через build_flags

| Флаг | Тип | Описание | Значение по умолчанию |
|------|-----|----------|----------------------|
| `FEATURE_LOGGER_ENABLED` | `int` (0/1) | Включить логирование | 1 |
| `XLOG_LEVEL` | `int` (0-4) | Максимальный уровень | 4 (DEBUG) |
| `XLOG_CATEGORIES` | `uint32_t` | Битовая маска категорий | `0xFFFFFFFF` (все) |
| `XLOG_USE_COLOR` | `int` (0/1) | Цветной вывод | 1 |
| `MONITOR_SPEED` | `int` | Скорость Serial (бод) | 115200 |

Внутренний флаг `USE_LOGGER` определяется в `settings.h` на основе `FEATURE_LOGGER_ENABLED`.

**Пример:**
```ini
build_flags =
    -D FEATURE_LOGGER_ENABLED=1
    -D XLOG_LEVEL=3
    -D XLOG_CATEGORIES=0x00001FFF
    -D XLOG_USE_COLOR=0
```

**Примечание:** при `FEATURE_LOGGER_ENABLED=0` все макросы становятся пустыми, код логирования исключается из прошивки.

## 6. Цветной вывод

Цвета используются для визуального различения уровней:

| Уровень | Цвет | ANSI-код |
|---------|------|----------|
| ERROR | Красный | `ANSI_BRIGHT_RED` |
| WARN | Маджента | `ANSI_BRIGHT_MAGENTA` |
| INFO | Обычный | `ANSI_RESET` |
| DEBUG | Синий | `ANSI_BLUE` |

**Правила:**
- Цвета можно отключить через `XLOG_USE_COLOR=0` или `log_set_color(false)`
- Цвета выводятся только если Serial поддерживает ANSI (терминал, PlatformIO)
