# LED_MANAGER.md

## Светодиодная индикация


## 1. Назначение

LED-слой обеспечивает визуальную индикацию состояния устройства. 

Менеджер не содержит логики — он получает готовый режим от оркестратора и применяет его.

## 2. Режимы индикации

| Режим | Сигнал | Период | Длительность импульса | Назначение |
|-------|--------|--------|----------------------|------------|
| `LED_OFF` | Постоянно выключен | — | — | Сохранение настроек / перезагрузка |
| `LED_ON` | Постоянно включён | — | — | Нормальная работа (WiFi + MQTT) |
| `LED_MORZE_E` | Одиночные вспышки | 1000 мс | 100 мс | Потеря WiFi или кнопка нажата 0-1с |
| `LED_MORZE_I` | Двойные вспышки | 1000 мс | 100 мс (каждая) | Потеря MQTT или кнопка нажата 1-2с |
| `LED_MORZE_S` | Тройные вспышки | 1000 мс | 100 мс (каждая) | Режим настройки (AP) или кнопка нажата >2с |
| `LED_SLOW_BLINK` | Медленное мигание | 2000 мс | 1000 мс | Аварийное отключение (emergency) |

## 3. Детали паттернов

### 3.1. MORZE_E (1 точка)
- 1 вспышка длительностью 100 мс
- Пауза 900 мс
- Полный цикл — 1000 мс

### 3.2. MORZE_I (2 точки)
- 2 вспышки по 100 мс каждая
- Интервал между вспышками — 100 мс
- Пауза после цикла — 700 мс
- Полный цикл — 1000 мс

### 3.3. MORZE_S (3 точки)
- 3 вспышки по 100 мс каждая
- Интервал между вспышками — 100 мс
- Пауза после цикла — 500 мс
- Полный цикл — 1000 мс

### 3.4. SLOW_BLINK (аварийное отключение)
- Длительный импульс 1000 мс
- Пауза 1000 мс
- Полный цикл — 2000 мс

## 4. API

| Функция | Назначение |
|---------|------------|
| `led_init()` | Инициализация пина (pinMode, начальное состояние) |
| `led_set_mode(mode)` | Установка режима индикации |
| `led_update()` | Обновление физического состояния (вызывается в loop) |

**Особенности:**
- `led_set_mode()` логирует смену режима (уровень DEBUG)
- `led_update()` работает асинхронно (не блокирует остальные процессы)

## 5. Логика переключения режимов (в оркестраторе)

Оркестратор (`main.cpp`) определяет режим LED на основе `SystemState`:

```cpp
// Индикатор LED
if (bits & STATE_RESTART) {
    led_set_mode(LED_OFF);
} else if (bits & STATE_EMERGENCY) {
    led_set_mode(LED_SLOW_BLINK);
} else if (bits & STATE_PROVISIONING) {
    led_set_mode(LED_MORZE_S);
} else if (bits & STATE_BUTTON_PRESSED) {
    if (stage == STAGE_3S || stage == STAGE_2S) {
        led_set_mode(LED_MORZE_S);
    } else if (stage == STAGE_1S) {
        led_set_mode(LED_MORZE_I);
    } else {
        led_set_mode(LED_MORZE_E);
    }
} else if (!(bits & STATE_WIFI_OK)) {
    led_set_mode(LED_MORZE_E);
#if FEATURE_MQTT_ENABLED
} else if (!(bits & STATE_MQTT_OK)) {
    led_set_mode(LED_MORZE_I);
#endif  // FEATURE_MQTT_ENABLED
} else {
    led_set_mode(LED_ON);
}
led_update();
```

**Приоритеты (от высшего к низшему):**

| Приоритет | Режим | Условие |
|-----------|-------|---------|
| **1 (высший)** | `LED_OFF` | `STATE_RESTART` |
| **2** | `LED_SLOW_BLINK` | `STATE_EMERGENCY` |
| **3** | `LED_MORZE_S` | `STATE_PROVISIONING` |
| **4** | `LED_MORZE_*` | `STATE_BUTTON_PRESSED` (в зависимости от стадии) |
| **5** | `LED_MORZE_E` | Нет `STATE_WIFI_OK` |
| **6** | `LED_MORZE_I` | Нет `STATE_MQTT_OK` (только если `FEATURE_MQTT_ENABLED`) |
| **7 (низший)** | `LED_ON` | Всё работает |

## 6. Флаги компиляции

| Флаг | По умолчанию | Описание |
|------|--------------|----------|
| `FEATURE_LED_ENABLED` | 1 | Включить LED-индикацию |
| `STATUS_LED_PIN` | 0 (отключена) | Номер пина светодиода. `0` — индикация отключена |
| `LED_INVERTED` | 0 (ESP32) / 1 (ESP8266) | Инверсия логики. `0` = HIGH включён, `1` = LOW включён |

**Примечание:** Для ESP8266 инверсия включена по умолчанию, так как встроенный светодиод на многих платах зажигается при LOW.

### 7.1. Файлы

| `led_manager.h` | API и конфигурация |
| `led_manager.cpp` | Реализация паттернов мигания |

### 7.2. Особенности

- При `FEATURE_LED_ENABLED == 0` все функции превращаются в пустые `inline` (экономия Flash)
- При `STATUS_LED_PIN == 0` индикация отключена (можно использовать без LED)
- Состояние пина обновляется только при изменении
