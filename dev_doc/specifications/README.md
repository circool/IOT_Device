# Спецификации проекта

**Важно** В папке находятся неактуальные версии - все они подлежать исправлению

Эта папка содержит внешние требования к интерфейсам устройства. В отличие от основной документации, которая описывает внутреннюю архитектуру и реализацию, спецификации определяют поведение устройства "снаружи" — то, что видят внешние системы и пользователи.
