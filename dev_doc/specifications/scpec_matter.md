Matter — современный протокол умного дома, работающий поверх IP (WiFi, Thread). Обеспечивает унифицированное представление устройства и взаимодействие с экосистемами разных производителей.

**Принцип представления**

Устройство представляется как единый Matter-узел (Node), содержащий несколько конечных точек (Endpoints) с типами устройств и кластерами, описанными в спецификации Matter. Взаимодействие строится по модели:
`{Node ID} → {Endpoint} → {Cluster} → {Attribute}`

**Типы устройств (Device Types)**

Каждая конечная точка соответствует стандартизированному типу устройства:

| Endpoint | Device Type | Применимость |
|----------|-------------|--------------|
| 0 | Aggregator (0x000E) | Все типы (корневая точка) |
| 1 | Extended Color Light (0x010D) | Типы 1, 3 |
| 2 | Temperature Sensor (0x0302) | Типы 1, 2 |
| 3 | Humidity Sensor (0x0307) | Типы 1, 2 |

**Примечание:** Extended Color Light используется вместо Fan, так как спецификация Matter на момент написания не включает отдельный тип для вентилятора. Управление скоростью реализуется через атрибут `CurrentLevel`.

**Кластеры и атрибуты**

*Endpoint 1 — Extended Color Light (типы 1, 3):*

| Кластер | Обязательность | Атрибуты и команды |
|---------|---------------|---------------------|
| Identify (0x0003) | Обязательный | `Identify` — визуальная идентификация устройства |
| On/Off (0x0006) | Обязательный | `OnOff` — состояние; команды `On`, `Off`, `Toggle` |
| Level Control (0x0008) | Обязательный | `CurrentLevel` — скважность ШИМ; команда `MoveToLevel` |
| Groups (0x0004) | Обязательный | Групповое управление |

*Endpoint 2 — Temperature Sensor (типы 1, 2):*

| Кластер | Обязательность | Атрибуты |
|---------|---------------|----------|
| Temperature Measurement (0x0402) | Обязательный | `MeasuredValue` — текущая температура |

*Endpoint 3 — Humidity Sensor (типы 1, 2):*

| Кластер | Обязательность | Атрибуты |
|---------|---------------|----------|
| Relative Humidity Measurement (0x0405) | Обязательный | `MeasuredValue` — текущая влажность |

*Общие кластеры (все конечные точки):*

| Кластер | Назначение |
|---------|------------|
| Descriptor (0x001D) | Идентификация типа устройства и состава конечной точки |
| Basic Information (0x0028) | `VendorName`, `ProductName`, `SoftwareVersion`, причина перезагрузки |
| OTA Software Update (0x002A) | Обновление прошивки по воздуху |

*Пользовательские параметры:*

Пороги датчика, таймеры и настройки режимов вынесены в пользовательский кластер на Endpoint 0 (Aggregator):

| Кластер | Атрибуты |
|---------|----------|
| Custom (0xFC00) | `SensorControlMode`, `AdaptiveMode`, `LowTemp`, `HighTemp`, `LowHum`, `HighHum`, `DelaySeconds`, `MaxOnTime` |

**Типы взаимодействия**

| Кластер | Публикация | Управление |
|---------|-----------|------------|
| On/Off | Да. Подписка на атрибут `OnOff` | Да. Команды `On`, `Off`, `Toggle` |
| Level Control | Да. Подписка на атрибут `CurrentLevel` | Да. Команда `MoveToLevel` |
| Temperature Measurement | Да. Подписка на атрибут | Нет |
| Relative Humidity Measurement | Да. Подписка на атрибут | Нет |
| Basic Information | Да. Статические атрибуты | Нет |
| OTA Software Update | Нет | Да. Приём обновлений |
| Custom | Да. Подписка на атрибуты | Да. `WriteAttribute` |

**Особенности:**
- Matter использует модель «подписок» (subscriptions) вместо периодической публикации: контроллер подписывается на атрибуты и получает обновления при их изменении.
- Устройство поддерживает multi-admin: одновременную работу с несколькими экосистемами (Apple Home, Google Home, Amazon Alexa и др.).
- Настройка выполняется через стандартную процедуру комиссионинга (commissioning) с QR-кодом или числовым кодом.
- OTA-обновления инициируются со стороны Matter-контроллера.
