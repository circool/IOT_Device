# Спецификация логирования

## 1. Общие принципы

- Логирование используется для диагностики и отладки устройства.
- Вывод осуществляется в последовательный порт (Serial).
- Реализован как синглтон с единой точкой доступа.
- Поддерживается фильтрация по уровню и категориям.
- Поддерживается цветной вывод в ANSI-совместимых терминалах.

---

## 2. Уровни логирования

Уровень логирования задаётся макросом `LOG_LEVEL` в `settings.h` или через `build_flags` в `platformio.ini`:

| Значение | Уровень | Описание |
|----------|---------|----------|
| 0 | NONE | Логирование отключено полностью |
| 1 | ERROR | Только критические ошибки |
| 2 | WARN | Предупреждения + ERROR |
| 3 | INFO | Основные события (подключение, переключение режимов) + WARN + ERROR |
| 4 | DEBUG | Все сообщения, включая отладочные (по умолчанию) |

**Пример установки в platformio.ini:**
```ini
build_flags =
    -DLOG_LEVEL=3
```

---

## 3. Категории логирования

Категории позволяют фильтровать сообщения по модулям. Значение `LOG_CATEGORIES` — битовая маска.

| Категория | Бит | Значение | Описание |
|-----------|-----|----------|----------|
| CAT_CONFIG | 1 << 0 | 1 | Конфигурация и EEPROM |
| CAT_SENSOR | 1 << 1 | 2 | Датчик температуры/влажности |
| CAT_FAN | 1 << 2 | 4 | Вентилятор (управление, ШИМ) |
| CAT_SWITCH | 1 << 3 | 8 | Выключатель |
| CAT_ACTUATOR | 1 << 4 | 16 | Исполнительный механизм |
| CAT_MQTT | 1 << 5 | 32 | MQTT-клиент (подключение, публикации) |
| CAT_WIFI | 1 << 6 | 64 | WiFi (подключение, AP режим) |
| CAT_WEB | 1 << 7 | 128 | Веб-сервер |
| CAT_OTA | 1 << 8 | 256 | OTA обновления |
| CAT_LED | 1 << 9 | 512 | Светодиодная индикация |
| CAT_WDT | 1 << 10 | 1024 | Watchdog таймер |
| CAT_AP | 1 << 11 | 2048 | Режим точки доступа |
| CAT_MAIN | 1 << 12 | 4096 | Основной цикл и инициализация |
| CAT_ALL | 0xFFFF | 65535 | Все категории |

**Комбинации категорий:**

| Значение | Включённые категории |
|----------|---------------------|
| `0xFFFF` | Все категории (по умолчанию) |
| `0x0001` | Только CAT_CONFIG |
| `0x0060` | CAT_MQTT + CAT_WIFI (32+64) |
| `0x0FFF` | Все категории, кроме CAT_MAIN |

**Пример включения только WiFi и MQTT логов:**
```ini
build_flags =
    -DLOG_CATEGORIES=0x0060
```

---

## 4. Цветной вывод

Цветной вывод логов в терминал включён по умолчанию (`LOG_USE_COLOR = 1`). Уровни имеют следующие цвета:

| Уровень | Цвет |
|---------|------|
| ERROR | Ярко-красный |
| WARN | Ярко-пурпурный |
| INFO | Стандартный (сброс) |
| DEBUG | Синий |

**Отключение цветов:**
```ini
build_flags =
    -DLOG_USE_COLOR=0
```

---

## 5. Формат вывода

### Цветной режим
```
[УРОВЕНЬ] [КАТЕГОРИЯ] Сообщение
```
- Цвет сообщения соответствует уровню.
- Строка начинается со сброса цвета для корректного отображения в терминалах.

### Монохромный режим
```
[УРОВЕНЬ] [КАТЕГОРИЯ] Сообщение
```

---

## 6. API модуля

| Метод | Назначение |
|-------|------------|
| `Logger::getInstance()` | Получение экземпляра логгера (синглтон) |
| `begin(level, categories, useColor)` | Инициализация с параметрами фильтрации |
| `setLevel(level)` | Изменение уровня логирования |
| `setCategories(categories)` | Изменение разрешённых категорий |
| `setColorEnabled(enabled)` | Включение/отключение цветного вывода |
| `log(level, category, format, ...)` | Основной метод логирования (printf-стиль) |
| `isEnabled(level, category)` | Проверка, нужно ли логировать |

---

## 7. Макросы для логирования

Для добавления логов в код используются макросы:

| Макрос | Уровень | Назначение |
|--------|---------|------------|
| `LOG_ERROR(cat, fmt, ...)` | ERROR | Критические ошибки |
| `LOG_WARN(cat, fmt, ...)` | WARN | Предупреждения |
| `LOG_INFO(cat, fmt, ...)` | INFO | Основные события |
| `LOG_DEBUG(cat, fmt, ...)` | DEBUG | Отладочная информация |

Где `cat` — одна из категорий из таблицы выше.

**Примеры:**
```cpp
LOG_ERROR(CAT_SENSOR, "Датчик не отвечает: %s", errorMsg);
LOG_WARN(CAT_WIFI, "Потеря соединения, попытка %d", attempt);
LOG_INFO(CAT_MAIN, "Устройство инициализировано, версия %s", VERSION);
LOG_DEBUG(CAT_MQTT, "Публикация в топик %s, данные: %.2f", topic, value);
```

---

## 8. Флаги компиляции

| Флаг | Значение по умолчанию | Назначение |
|------|----------------------|------------|
| `MONITOR_SPEED` | 115200 | Скорость последовательного порта |
| `LOG_LEVEL` | 3 (INFO) | Уровень логирования |
| `LOG_CATEGORIES` | 0xFFFF | Категории логирования |
| `LOG_USE_COLOR` | 1 | Цветной вывод |

---

## 9. Особенности реализации

- Логи выводятся в последовательный порт (`Serial`) со скоростью `MONITOR_SPEED`.
- При включённом цветном выводе логгер автоматически сбрасывает цвет перед каждой строкой для корректного отображения в терминалах.
- Сообщения длиннее 256 символов обрезаются.
- При уровне `LOG_LEVEL_NONE (0)` все макросы логирования превращаются в пустые операции, не потребляя ресурсы.
- Если логгер не инициализирован (`begin()` не вызван), все вызовы `log()` игнорируются.

---

## 10. Примеры настройки в platformio.ini

```ini
[common]
build_flags =
    ; Только ошибки и предупреждения, без отладочных сообщений
    -DLOG_LEVEL=2
    
    ; Только MQTT и WiFi логи
    -DLOG_CATEGORIES=0x0060
    
    ; Монохромный вывод (без ANSI-цветов)
    -DLOG_USE_COLOR=0
```
