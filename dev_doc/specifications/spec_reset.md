# Спецификация кнопки сброса (исправленная)

## 1. Общие принципы

- Кнопка сброса используется для принудительного сброса всех настроек к значениям по умолчанию.
- Сброс выполняется только при длительном удержании кнопки (3 секунды).
- Короткое нажатие игнорируется (защита от случайного срабатывания).
- Модуль кнопки **только** подсчитывает время удержания. Логика реакции выполняется в оркестраторе.

---

## 2. Аппаратная конфигурация

| Параметр | Значение | Назначение |
|----------|----------|------------|
| Пин | `RESET_PIN` (определяется в `settings.h`) | Номер GPIO для кнопки сброса |
| Подтяжка | Внутренняя (INPUT_PULLUP) | Кнопка замыкает на GND |
| Активный уровень | LOW | Нажатое состояние |

---

## 3. API модуля

| Функция | Назначение |
|---------|------------|
| `reset_button_init()` | Инициализация пина кнопки |
| `reset_button_getPressTime()` | Возвращает время удержания кнопки в миллисекундах. Возвращает 0, если кнопка не нажата |

---

## 4. Флаги компиляции

| Флаг | Значение | Назначение |
|------|----------|------------|
| `RESET_PIN` | Номер пина | Пин кнопки сброса |
| `RESET_DELAY_SEC` | 3 | Время удержания кнопки для активации сброса (сек) |
