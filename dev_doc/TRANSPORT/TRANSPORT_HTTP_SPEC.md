## 1. Назначение

Документ описывает **внешнее поведение** HTTP-интерфейса: страницы, блоки, поля, параметры команд.

**Документ НЕ описывает:**
- Внутреннюю архитектуру HTTP-протокола (это `TRANSPORT_HTTP.md`)
- Механизмы получения данных (это `TRANSPORT_HTTP.md`)
- Взаимодействие с оркестратором (это `TRANSPORT_HTTP.md`)

## 2. Страницы

### 2.1. Страница состояния (`/`)

**Доступ:** Режим NORMAL

**Назначение:** Отображение текущего состояния устройства и оперативное управление.

**Макет:**

```
┌────────────────────────────────────────────┐
│               fan_1A2B  v1.8.0             │
│                                            │
│  ┌──────────────┐        ┌──────────────┐  │
│  │  24.5 °C     │        │  45.2 %      │  │
│  │ Temperature  │        │  Humidity    │  │
│  │  off: 27.0   │        │  off: 55.0   │  │
│  │  on: 29.0    │        │  on: 60.0    │  │
│  └──────────────┘        └──────────────┘  │
│                                            │
│  ┌──────────────────────────────────────┐  │
│  │              Device: ON              │  │
│  │             [ TURN OFF ]             │  │
│  └──────────────────────────────────────┘  │
│                                            │
│  ┌──────────────────────────────────────┐  │
│  │  Speed: 75%                          │  │
│  │  ████████████████████░░░░░░░░░░░░░░  │  │
│  │  [ -20% ]                  [ +20% ]  │  │
│  └──────────────────────────────────────┘  │
│                                            │
│  ┌──────────────────────────────────────┐  │
│  │  Mode: SENSOR                        │  │
│  │  [ TURN MANUAL MODE ]                │  │
│  └──────────────────────────────────────┘  │
│                                            │
│  ┌──────────────────────────────────────┐  │
│  │  Adaptive: ON                        │  │
│  │  [ TURN ADAPTIVE OFF ]               │  │
│  └──────────────────────────────────────┘  │
│                                            │
│  ┌──────────────────────────────────────┐  │
│  │  Link:  ✅ OK     Gateway:  ✅ OK    │  │
│  │  RSSI: -54 dBm                       │  │
│  └──────────────────────────────────────┘  │
│                                            │
│  ──────────────────────────────────────    │
│  Delay: 60 sec (remain: 45 sec)            │
│  Max On Time: 3600 sec (remain: 1800 sec)  │
│                                            │
│  [ Settings ]                              │
└────────────────────────────────────────────┘
```

**Блоки управления:**

| Блок | Элементы | Назначение |
|------|----------|------------|
| **Актуатор** | Статус (ON/OFF) + кнопка | Включить/выключить |
| **Скорость** | Шкала + кнопки `-20%` / `+20%` | Изменение скорости с шагом 20% |
| **Режим** | Текст (SENSOR/MANUAL) + кнопка | Переключение между SENSOR и MANUAL |
| **Адаптивный** | Текст (ON/OFF) + кнопка | Включить/выключить адаптивный режим |

**Кнопки управления:**

| Кнопка | Условие | Команда |
|--------|---------|---------|
| `[ TURN OFF ]` | Device: ON | `/set?state=off` |
| `[ TURN ON ]` | Device: OFF | `/set?state=on` |
| `[ -20% ]` | Speed > 0 | `/set?speed={speed-20}` |
| `[ +20% ]` | Speed < 100 | `/set?speed={speed+20}` |
| `[ TURN MANUAL MODE ]` | Mode: SENSOR | `/set?sensorControlMode=0` |
| `[ TURN SENSOR MODE ]` | Mode: MANUAL | `/set?sensorControlMode=1` |
| `[ TURN ADAPTIVE OFF ]` | Adaptive: ON | `/set?adaptiveMode=0` |
| `[ TURN ADAPTIVE ON ]` | Adaptive: OFF | `/set?adaptiveMode=1` |

**Примечания:**
- Кнопки меняют текст в зависимости от текущего состояния.
- Кнопки `+/- SPEED` изменяют скорость с шагом 20%.
- Автообновление страницы — 5 секунд (настраивается через `DEFAULT_WEB_REFRESH`).

### 2.2. Страница настроек (`/config`)

**Доступ:** Режим NORMAL

**Назначение:** Изменение параметров устройства и транспорта.

**Макет:**

```
┌──────────────────────────────────────┐
│  НАСТРОЙКИ                           │
│                                      │
│  ─── НАСТРОЙКИ ТРАНСПОРТА ───        │
│  WiFi SSID:        [MyWiFi________]  │
│  WiFi Password:    [*************]   │
│  MQTT Broker:      [192.168.1.100_]  │
│  MQTT Port:        [1883________]    │
│  MQTT User:        [user________]    │
│  MQTT Password:    [*************]   │
│  [✓] Confirm saving (required)       │
│  [ Save Transport ]                  │
│                                      │
│  ─── НАСТРОЙКИ УСТРОЙСТВА ───        │
│  Low Temp:         [26.0_______]     │
│  High Temp:        [30.0_______]     │
│  Low Hum:          [50.0_______]     │
│  High Hum:         [65.0_______]     │
│  Delay Seconds:    [60_________]     │
│  Max On Time:      [3600_______]     │
│  Sensor Mode:      [✓] AUTO          │
│  Adaptive Mode:    [✓] ON            │
│  Boot State:       [✓] ON            │
│  [✓] Confirm saving (required)       │
│  [ Save Device ]                     │
└──────────────────────────────────────┘
```

**Чекбокс подтверждения:**
- Поле `confirmSave` — обязательно для заполнения (required)
- По умолчанию — снят
- Предназначен для предотвращения случайного сохранения

**Примечания:**
- Две независимые формы на одной странице.
- Каждая форма имеет свой обработчик.
- Пароли отображаются как `(hidden)` и не передаются в форме (оставляются как есть).
- Чекбокс `confirmSave` обязателен для обеих форм.

### 2.3. Страница результата

**Назначение:** Уведомление пользователя о результате сохранения.

**Макет (успех):**

```
┌──────────────────────────────────────────────────────┐
│  ✅ Settings saved successfully                      │
│                                                      │
│  Redirecting to settings page...                     │
└──────────────────────────────────────────────────────┘
```

**Макет (ошибка):**

```
┌──────────────────────────────────────────────────────┐
│  ❌ Error: Low temperature out of range              │
│                                                      │
│  Please try again.                                   │
│  Redirecting to settings page...                     │
└──────────────────────────────────────────────────────┘
```

**Поведение:**
- Автоматический редирект на `/config` через 2–3 секунды.
- При успехе — зелёное уведомление.
- При ошибке — красное уведомление с описанием.

## 3. Блоки

### 3.1. Карточка температуры

**CSS-классы:**
- `.card .info` — норма (в пределах порогов)
- `.card .warning` — превышение верхнего порога
- `.card .danger` — критическое превышение
- `.card .cold` — ниже нижнего порога

**Данные:**
- Текущая температура (`temperature`)
- Нижний порог (`lowTemp`)
- Верхний порог (`highTemp`)

**Цветовая индикация:**
- `temperature > highTemp` → `.warning` (оранжевый)
- `temperature > highTemp + 5` → `.danger` (красный)
- `temperature < lowTemp` → `.cold` (синий)
- `lowTemp <= temperature <= highTemp` → `.info` (зелёный/нейтральный)

---

### 3.2. Карточка влажности

**CSS-классы:**
- `.card .info` — норма (в пределах порогов)
- `.card .warning` — превышение верхнего порога
- `.card .danger` — критическое превышение
- `.card .cold` — ниже нижнего порога

**Данные:**
- Текущая влажность (`humidity`)
- Нижний порог (`lowHum`)
- Верхний порог (`highHum`)

**Цветовая индикация:** Аналогично температуре.

---

### 3.3. Статус актуатора

**CSS-класс:** `.block .center .success` (ON), `.block .center .error` (OFF)

**Данные:**
- Состояние (`is_on`)
- Скорость (`speed`) — для TYPE 1

**Отображение:**
- ON → зелёный
- OFF → красный

---

### 3.4. Шкала скорости

**CSS-класс:** `.bar`, `.fill`

**Данные:**
- Скорость (`speed`) — 0–100%

**Отображение:** Графическая шкала с процентом.

---

### 3.5. Режим работы

**CSS-класс:** `.block .info`

**Данные:**
- Режим (`sensor_control_mode`): SENSOR / MANUAL
- Адаптивный режим (`adaptive_mode`): ON / OFF

---

### 3.6. Статус подключений

**CSS-класс:** `.status-block`

**Данные:**
- `link_ok` — OK / FAIL
- `gateway_ok` — OK / FAIL
- `link_quality` — RSSI в dBm (только для WiFi)

**Отображение:**

| Статус | Иконка | Цвет | CSS-класс |
|--------|--------|------|-----------|
| `link_ok` = true | ✅ | Зелёный | `.status-ok` |
| `link_ok` = false | ❌ | Красный | `.status-fail` |
| `gateway_ok` = true | ✅ | Зелёный | `.status-ok` |
| `gateway_ok` = false | ❌ | Красный | `.status-fail` |

**Визуальное выделение:**
- Блок имеет отдельный CSS-класс `.status-block` для визуального выделения на странице (рамка, фон, отступы).
- Иконки и цвета помогают быстро оценить состояние подключений.

**Пример:**

```
┌──────────────────────────────────────┐
│  Link:  ✅ OK   Gateway:  ✅ OK      │
│  RSSI: -54 dBm                       │
└──────────────────────────────────────┘
```

---

### 3.7. Информационная панель

**CSS-класс:** `.block .info`

**Данные:**
- Задержка включения (`delaySeconds`) и остаток (`delayRemain`)
- Аварийное отключение (`maxOnTime`) и остаток (`maxOnRemain`)
- Версия прошивки (`version`)
- Причина последней перезагрузки (`resetReason`) — отображается только если не NULL

**Пример:**
```
Delay: 60 sec (remain: 45 sec)
Max On Time: 3600 sec (remain: 1800 sec)
Version: 1.8.0
Last reset: WATCHDOG
```

**Поведение:**
- Если `reset_reason == NULL` — строка не отображается (CHECK ENGINE не горит).
- Если не NULL — отображается с классом `.error` и текстом причины (CHECK ENGINE горит).
```

## 4. Формы и поля

### 4.1. Форма настроек транспорта

**URL:** `/save/transport`

**Метод:** POST

**Поля:**

| Поле | Тип | Обязательное | Диапазон | Назначение |
|------|-----|--------------|----------|------------|
| `wifiSsid` | text | ✅ | 1–31 символов | WiFi SSID |
| `wifiPassword` | password | ❌ | 0–63 символов | WiFi пароль |
| `mqttBroker` | text | ❌ | — | MQTT брокер |
| `mqttPort` | number | ❌ | 1–65535 | MQTT порт |
| `mqttUser` | text | ❌ | — | MQTT пользователь |
| `mqttPassword` | password | ❌ | — | MQTT пароль |
| `confirmSave` | checkbox | ✅ | — | Подтверждение сохранения |

---

### 4.2. Форма настроек устройства

**URL:** `/save/device`

**Метод:** POST

**Поля (зависят от `DEVICE_TYPE`):**

#### TYPE 1 (вентилятор с датчиком)

| Поле | Тип | Обязательное | Диапазон | Назначение |
|------|-----|--------------|----------|------------|
| `lowTemp` | number | ✅ | `TEMP_MIN`–`TEMP_MAX` | Нижний порог температуры |
| `highTemp` | number | ✅ | `TEMP_MIN`–`TEMP_MAX` | Верхний порог температуры |
| `lowHum` | number | ✅ | `HUM_MIN`–`HUM_MAX` | Нижний порог влажности |
| `highHum` | number | ✅ | `HUM_MIN`–`HUM_MAX` | Верхний порог влажности |
| `delaySeconds` | number | ✅ | 0–86400 | Задержка включения |
| `maxOnTime` | number | ✅ | 0–86400 | Аварийное отключение |
| `sensorControlMode` | checkbox | ❌ | 0/1 | SENSOR / MANUAL |
| `adaptiveMode` | checkbox | ❌ | 0/1 | Адаптивный режим |
| `bootState` | checkbox | ❌ | 0/1 | Состояние при старте |
| `confirmSave` | checkbox | ✅ | — | Подтверждение сохранения |

#### TYPE 2 (автономный датчик)

Нет настроек устройства (только чтение датчика).

#### TYPE 3 (управляемый выключатель)

| Поле | Тип | Обязательное | Диапазон | Назначение |
|------|-----|--------------|----------|------------|
| `delaySeconds` | number | ✅ | 0–86400 | Задержка включения |
| `maxOnTime` | number | ✅ | 0–86400 | Аварийное отключение |
| `bootState` | checkbox | ❌ | 0/1 | Состояние при старте |
| `confirmSave` | checkbox | ✅ | — | Подтверждение сохранения |

## 5. Оперативные команды (`/set`)

**Метод:** GET

**Назначение:** Быстрое изменение параметров без перезагрузки.

**Параметры:**

| Параметр | Тип | Диапазон | Назначение | Применимость |
|----------|-----|----------|------------|--------------|
| `state` | `on`/`off` | — | Включить/выключить актуатор | TYPE 1, 3 |
| `speed` | number | 0–100 | Установить скорость | TYPE 1 |
| `sensorControlMode` | 0/1 | — | Включить/выключить SENSOR | TYPE 1 |
| `adaptiveMode` | 0/1 | — | Включить/выключить адаптивный | TYPE 1 |

**Примеры:**
- `/set?state=on` — включить
- `/set?speed=75` — скорость 75%
- `/set?sensorControlMode=1` — включить SENSOR
