## 1. Назначение

Документ описывает **внешнее поведение** ZCL-протокола: конечные точки, кластеры, атрибуты, команды.

**Документ НЕ описывает:**
- Внутреннюю архитектуру Zigbee-транспорта (это `TRANSPORT_ZIGBEE.md`)
- Механизмы получения данных (это `TRANSPORT_ZIGBEE.md`)

## 2. Конечные точки (Endpoints)

Устройство представляет **три конечные точки**:

| Endpoint | Назначение | Применимость |
|----------|------------|--------------|
| **1** | Управление вентилятором / выключателем | TYPE 1, 3 |
| **2** | Датчик температуры и влажности | TYPE 1, 2 |
| **3** | Конфигурация устройства | Все типы |

---

## 3. Кластеры и атрибуты

### 3.1. Endpoint 1 — Управление (TYPE 1, 3)

| Кластер | ID | Тип | Атрибуты |
|---------|-----|-----|----------|
| **On/Off** | 0x0006 | Сервер | `OnOff` (bool) — состояние актуатора |
| **Level Control** | 0x0008 | Сервер | `CurrentLevel` (0-100%) — скорость ШИМ |
| **Fan Control** | 0x0202 | Сервер | `FanMode` — режим работы; `FanModeSequence` — адаптивный режим |

### 3.2. Endpoint 2 — Датчик (TYPE 1, 2)

| Кластер | ID | Тип | Атрибуты |
|---------|-----|-----|----------|
| **Temperature Measurement** | 0x0402 | Сервер | `MeasuredValue` — температура (°C × 100) |
| **Relative Humidity Measurement** | 0x0405 | Сервер | `MeasuredValue` — влажность (% × 100) |

**Примечание:** Zigbee использует масштабированные значения: температура × 100, влажность × 100.

### 3.3. Endpoint 3 — Конфигурация (Все типы)

| Кластер | ID | Тип | Атрибуты |
|---------|-----|-----|----------|
| **Basic** | 0x0000 | Сервер | `ManufacturerName`, `ModelIdentifier`, `SWBuildID` |
| **OTA Upgrade** | 0x0019 | Клиент | Обновление прошивки |
| **Custom (пользовательский)** | 0xFC00 | Сервер | Пороги, таймеры, режимы |

**Пользовательский кластер (0xFC00):**

| Атрибут | ID | Тип | Назначение |
|---------|-----|-----|------------|
| `LowTemp` | 0x0000 | int16 | Нижний порог температуры (°C × 100) |
| `HighTemp` | 0x0001 | int16 | Верхний порог температуры (°C × 100) |
| `LowHum` | 0x0002 | uint16 | Нижний порог влажности (% × 100) |
| `HighHum` | 0x0003 | uint16 | Верхний порог влажности (% × 100) |
| `DelaySeconds` | 0x0004 | uint16 | Задержка включения (сек) |
| `MaxOnTime` | 0x0005 | uint32 | Аварийное отключение (сек) |
| `SensorControlMode` | 0x0006 | bool | Режим SENSOR / MANUAL |
| `AdaptiveMode` | 0x0007 | bool | Адаптивный режим |
| `BootState` | 0x0008 | bool | Состояние при старте |
| `SpeedPercent` | 0x0009 | uint8 | Скорость (0-100%) |

## 4. Типы взаимодействия

| Кластер | Публикация | Управление | Механизм |
|---------|-----------|------------|----------|
| **On/Off** | ✅ Да | ✅ Да | Отчёты атрибутов + команды `On`/`Off` |
| **Level Control** | ✅ Да | ✅ Да | Отчёты + команда `MoveToLevel` |
| **Fan Control** | ✅ Да | ✅ Да | Отчёты + `Write Attributes` |
| **Temperature Measurement** | ✅ Да | ❌ Нет | Периодические отчёты |
| **Relative Humidity** | ✅ Да | ❌ Нет | Периодические отчёты |
| **Basic** | ✅ Да | ❌ Нет | Статические атрибуты |
| **OTA Upgrade** | ❌ Нет | ✅ Да | Приём обновлений |
| **Custom (0xFC00)** | ✅ Да | ✅ Да | Отчёты + `Write Attributes` |

---

## 5. Отчёты атрибутов (Reporting)

Атрибуты, отмеченные как «Публикация: Да», поддерживают механизм отчётов:

1. Устройство настраивает периодичность отчётов при старте
2. Координатор подписывается на атрибуты
3. При изменении атрибута устройство отправляет отчёт
4. Отчёты также отправляются периодически (heartbeat)

**Периодичность отчётов:**

| Атрибут | Минимальный интервал | Максимальный интервал |
|---------|---------------------|---------------------|
| Температура | 5 сек | 300 сек |
| Влажность | 5 сек | 300 сек |
| Состояние (On/Off) | 0 (при изменении) | 60 сек |
| Скорость | 0 (при изменении) | 60 сек |

## 6. Команды

### 6.1. Команды управления (Endpoint 1)

| Кластер | Команда | Параметр | Назначение |
|---------|---------|----------|------------|
| On/Off | `On` | — | Включить |
| On/Off | `Off` | — | Выключить |
| On/Off | `Toggle` | — | Переключить состояние |
| Level Control | `MoveToLevel` | `level` (0-100) | Установить скорость |

### 6.2. Команды настройки (Endpoint 3)

| Кластер | Команда | Параметр | Назначение |
|---------|---------|----------|------------|
| Custom (0xFC00) | `Write Attributes` | Атрибут + значение | Изменить настройку |

## 7. Форматы данных

| Тип | Формат | Пример | Атрибуты |
|-----|--------|--------|----------|
| bool | 0x00 / 0x01 | `0x01` | `OnOff`, `SensorControlMode` |
| uint8 | 0-255 | `75` | `SpeedPercent` |
| int16 | × 100 | `2450` (24.5°C) | `MeasuredValue` (температура) |
| uint16 | × 100 | `4520` (45.2%) | `MeasuredValue` (влажность) |
| uint32 | 0-4294967295 | `3600` | `MaxOnTime` |
